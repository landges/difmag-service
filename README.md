# Сервис по отбору нечетких дубликтов изображений (difmag-service)
## Описание
Данный сервис представляет из себя готовый микросервис для отбора нечетких дубликатов изображений.
В качестве данных для механизма отбора используются эмбеддинги нейросети ResNet-50.
## Функционал
Приложение представляет из себя два контейнера: бекенд и БД (PostgreSQL). Бд вы можете вынести в свой кластер, предварительно поставив расширение pgvector.
Для удобного многопозвотельского режима и обработки массивов, расширяющихся с течением времени введен механизм профилирования
Профиль-это своеобразная метка вашего датасета, с которым вы работаете в течении некоторого времени.
Вы можете:
1. Создавать профили.
2. Удалять профили.
3. Удалять изображения из профиля

Загрузка изображений в сервис предполагает три варианта:

1. Загрузка предварительно отобранных уникальных изображений в профиль для последующего отбора.
2. Загрузка с проверкой. Каждое последующее загруженное изображение проверяется на нечетких дубликат с заданным пользователем порогом, при превышении которого может по желанию пользователя добавляться в профиль.
3. Разовая загрузка массива. Массив загружается без профиля, разово обрабатывается и пользователь может скачать уникальные изображения.
## Развертывание
### БД
Как указывалось выше, вы можете закоментировать в ```docker-compose.yaml``` PostgreSQL и перенести его в свой кластер для более высокой производительности.
### Модель
Можно прокинуть с помощью volumes свою модель для получения эмбеддингов, если ваш датасет специфичен.
### Хранение
Представлено в двух вариантах : Файловое храние и S3, задать которое можно в конфиге проекта.
